# IoT Anomaly Detection - Frontend Dashboard

An interactive dashboard for the **IoT Anomaly Detection System**, built as part of an MSc research project.

## 🚀 Features
- **Real-time Monitoring**: Visualizing sensor data streams.
- **Anomaly Highlighting**: Interactive charts highlighting detected anomalies.
- **Model Comparison**: Side-by-side comparison of different unsupervised algorithms.
- **Data Upload**: CSV upload interface for batch anomaly detection.

## 🛠️ Tech Stack
- Angular 17+
- TailwindCSS / Vanilla CSS
- Chart.js / NgCharts

## 🏁 Quick Start
```bash
npm install
npx ng serve
```
Access the dashboard at `http://localhost:4200`.

## 🔗 Connection
Ensure the `.NET Backend` is running on `http://localhost:5000`.
